Thêm kênh theo dõi

Hệ thống sẽ tự lấy tên, ảnh đại diện và danh sách video/danh sách phát thật của kênh. Cần có API Key (bấm ⚙️ API ở trên nếu chưa có).

Cài đặt YouTube Data API

Lấy miễn phí: vào Google Cloud Console → tạo dự án → bật "YouTube Data API v3" → tạo Credentials > API key → dán vào đây. Key chỉ lưu trên máy bạn (localStorage), không gửi đi đâu ngoài Google.
