Thêm kênh theo dõi

Hệ thống sẽ tự lấy tên, ảnh đại diện và danh sách video/danh sách phát thật của kênh. Cần có API Key (bấm ⚙️ API ở trên nếu chưa có).

Cài đặt

Lấy miễn phí: vào Google Cloud Console → tạo dự án → bật "YouTube Data API v3" → tạo Credentials > API key → dán vào đây. Key chỉ lưu trên máy bạn (localStorage), không gửi đi đâu ngoài Google.
Thêm/xóa kênh trên máy này sẽ tự động gửi thẳng cho mọi thiết bị khác — không cần tải file hay vào GitHub nữa. Cần tài khoản miễn phí: vào jsonbin.io → đăng ký → vào mục API Keys trong Dashboard → copy dòng X-MASTER-KEY → dán vào ô dưới đây.
Xuất file shared-content.json rồi tải lên đúng vị trí gốc của repo GitHub (kéo-thả qua trang web GitHub, không cần dòng lệnh).
Xuất ra file để lưu kênh, video, hồ sơ bé và mã PIN — gửi file này qua Zalo/email rồi nhập lại trên máy khác. File này KHÔNG chứa API key (mỗi máy cần tự nhập key riêng ở trên).
